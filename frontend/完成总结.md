# 🎉 Rosetta Blog System - Frontend Complete!

## 项目概览

已成功为 Rosetta 博客系统创建完整的 Nuxt 4 前端应用，包含公共博客页面（使用 shadcn/ui 风格设计）和管理后台（使用 NuxtUI 组件库）。

## ✅ 已完成的核心功能

### 1. 技术栈
- **框架**: Nuxt 4 (最新版本)
- **UI 组件**: NuxtUI (管理后台) + 自定义组件 (公共页面)
- **样式**: Tailwind CSS + 自定义设计系统
- **状态管理**: Pinia
- **国际化**: @nuxtjs/i18n (支持 zh/en/ja/zh_Hant)
- **类型系统**: TypeScript
- **包管理**: pnpm

### 2. 完整的 API 集成
所有后端 API 端点都已通过 composables 集成：

```typescript
// 文章相关
usePosts()      // 获取文章列表、详情、创建、更新、删除、点赞
useComments()   // 评论管理

// 分类和标签
useCategories() // 分类管理
useTags()       // 标签管理

// 核心功能
useAuth()       // 登录、注册、token 刷新
useCore()       // 站点配置、导航、友链、归档
useUsers()      // 用户资料、统计
useOOBE()       // 安装向导
```

### 3. 页面实现

#### 公共页面 (蓝色调设计)

## 🚀 快速开始

### 方式一：使用安装脚本（推荐）

**Windows**:
```bash
cd frontend
setup.bat
```

**Linux/Mac**:
```bash
cd frontend
chmod +x setup.sh
./setup.sh
```

### 方式二：手动安装

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖
pnpm install

# 3. 创建 .env 文件
echo "API_BASE_URL=http://localhost:8000/api" > .env

# 4. 启动开发服务器
pnpm dev
```

### 首次使用流程

1. **启动后端** - 确保后端运行在 `http://localhost:8000`
2. **访问 OOBE** - 打开 `http://localhost:3000/oobe`
3. **完成安装向导**:
   - 配置数据库
   - 设置站点信息
   - 创建管理员账户
4. **开始使用**:
   - 前台：`http://localhost:3000`
   - 后台：`http://localhost:3000/admin`
