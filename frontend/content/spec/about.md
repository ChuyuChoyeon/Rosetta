# 关于

欢迎来到本站！这里是我的个人博客，分享技术与生活。

本站使用 **Rosetta**（Nuxt 4 版本）构建：

- 🚀 前端：Vue 3 + Nuxt 4.5.2 + Tailwind v4
- 🎨 设计：@nuxt/ui + 自研设计令牌（one-light / one-dark-pro 双主题）
- 🔎 内容：@nuxt/content v3（Markdown + MDC）
- 🧠 状态：Pinia + Cookies 双份 Token
- ⚙️ 后端：FastAPI + SQLAlchemy + PostgreSQL + Redis（同源 /api 代理）
- 🖼️ 图片：@nuxt/image（AVIF / WebP 自动转码 + 响应式尺寸）
- 🌍 SEO：@nuxtjs/seo（sitemap / robots / OG / schema-org）

> **管理入口**：`/admin`。默认先经过 OOBE（首次配置）向导完成站点初始化与管理员创建。
